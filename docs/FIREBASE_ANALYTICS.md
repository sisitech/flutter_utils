# Firebase Analytics

A thin [GetX](https://pub.dev/packages/get) wrapper around [firebase_analytics](https://pub.dev/packages/firebase_analytics) and [firebase_core](https://pub.dev/packages/firebase_core). It handles Firebase initialization, auth-aware user identification, a generic `logEvent` passthrough, and intent-revealing helpers for the predefined Firebase events plus custom domain events (e.g. M-Pesa / Wavvy Wallet).

It mirrors the existing `MixPanelController` pattern, so if you already use that, this will feel identical.

## Key Features

- **GetX service**: `FirebaseAnalyticsController extends GetxController` — register once with `Get.put`, use anywhere with `Get.find`.
- **Auto initialization**: calls `Firebase.initializeApp` for you on `onInit` (or manually, see [Manual init](#manual-init)).
- **Auth-aware user identity**: reads the logged-in profile from `flutter_auth`'s `AuthController` and sets the Firebase user id (md5-hashed when anonymized).
- **Debug-safe**: `disableInDebug` / `enabled` flags let you suppress events in development.
- **Automatic screen tracking**: exposes a `FirebaseAnalyticsObserver` for `screen_view` events.
- **Predefined + custom events**: semantic helpers for auth, subscription/monetization, and engagement events, plus thin wrappers for app-specific custom events. The generic `logEvent` supports anything else.

## Installation & Setup

### 1. Dependencies

Add to your app's `pubspec.yaml`:

```yaml
dependencies:
  firebase_core: ^3.6.0
  firebase_analytics: ^11.3.3
  get: ^4.6.0
  flutter_utils:
    git:
      url: git@github.com:sisitech/flutter_utils.git
    # or, for local development:
    # path: ../flutter_utils
```

> **`flutter_auth` is required.** The controller calls `Get.find<AuthController>()` for user
> identification, so your app must already depend on `flutter_auth` and register
> `Get.put(AuthController())` **before** the analytics controller.

Then run:

```bash
flutter pub get
```

### 2. Connect your app to Firebase (FlutterFire)

Generate the `firebase_options.dart` that links your app to a Firebase project:

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

This creates `lib/firebase_options.dart` (exposing `DefaultFirebaseOptions.currentPlatform`) and
wires the native config (`google-services.json` on Android, `GoogleService-Info.plist` on iOS)
automatically. See the [FlutterFire docs](https://firebase.flutter.dev/docs/overview/) for details.

## Quick Start

```dart
import 'package:flutter/material.dart';
import 'package:flutter_auth/flutter_auth_controller.dart';
import 'package:flutter_utils/firebase_analytics/firebase_analytics_controller.dart';
import 'package:get/get.dart';
import 'package:get_storage/get_storage.dart';

import 'firebase_options.dart'; // generated by `flutterfire configure`

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await GetStorage.init();

  // Must be registered before FirebaseAnalyticsController.
  Get.put(AuthController());

  // Registers and auto-initializes Firebase Analytics.
  var analytics = Get.put(FirebaseAnalyticsController(
    firebaseOptions: DefaultFirebaseOptions.currentPlatform,
    options: const FirebaseAnalyticsOptions(
      disableInDebug: false, // set true to silence events in debug builds
    ),
  ));

  runApp(MyApp(analytics: analytics));
}

class MyApp extends StatelessWidget {
  final FirebaseAnalyticsController analytics;
  const MyApp({super.key, required this.analytics});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'My App',
      // Automatic screen_view tracking on every route change.
      navigatorObservers: [analytics.observer],
      home: const HomePage(),
    );
  }
}
```

Anywhere else in the app, grab the controller and log events:

```dart
var analytics = Get.find<FirebaseAnalyticsController>();
analytics.userLogsIn(method: "email");
```

## Configuration options

`FirebaseAnalyticsOptions`:

| Option | Type | Default | Description |
|---|---|---|---|
| `enabled` | `bool` | `true` | Master on/off switch for analytics. |
| `disableInDebug` | `bool` | `true` | When `true`, events are **not** disabled in debug — debug runs behave as enabled. Set `false` to honor `enabled` everywhere. *(matches `MixpanelOptions` semantics.)* |
| `analyticsCollectionEnabled` | `bool` | `true` | Passed to `setAnalyticsCollectionEnabled` after init. |
| `enableAnonymous` | `bool` | `true` | When `true`, the user id is the md5 hash of the user's email instead of the raw value. |
| `enableManualInit` | `bool` | `false` | When `true`, skips auto-init in `onInit`; you must call `analytics.initialize()` yourself. |

## Usage

Get the controller anywhere with `Get.find<FirebaseAnalyticsController>()`.

### Generic (any event)

```dart
final analytics = Get.find<FirebaseAnalyticsController>();

// Arbitrary custom event
analytics.logEvent("promo_banner_tapped", parameters: {"banner_id": "june_2026"});

// Manual screen view
analytics.logScreen("DashboardPage", screenClass: "DashboardPage");

// User properties / id
analytics.setUserProperty("subscription_tier", "premium");
analytics.setUserId("user_123");
```

### Auth & onboarding

```dart
analytics.userLogsIn(method: "email");      // login
analytics.userSignsUp(method: "email");     // sign_up
analytics.tutorialBegin();                  // tutorial_begin
analytics.tutorialComplete();               // tutorial_complete
```

### Subscription / monetization

```dart
import 'package:firebase_analytics/firebase_analytics.dart';

final premium = AnalyticsEventItem(
  itemId: "plan_premium_monthly",
  itemName: "Premium Monthly",
  price: 199.0,
  currency: "KES",
);

analytics.viewsPlans([premium], listName: "Subscription Plans"); // view_item_list
analytics.selectsPlan(premium);                                   // select_item
analytics.beginsCheckout(value: 199.0, currency: "KES", items: [premium]); // begin_checkout
analytics.addsPaymentInfo(paymentType: "mpesa", value: 199.0, currency: "KES"); // add_payment_info

// Subscription paid / renewed -> purchase
analytics.subscribes(
  value: 199.0,
  currency: "KES",
  transactionId: "SUB-2026-0001",
  items: [premium],
);

analytics.refunds(value: 199.0, currency: "KES", transactionId: "SUB-2026-0001"); // refund
```

### Engagement

```dart
analytics.searchesTransactions("Naivas");                          // search
analytics.selectsContent(contentType: "transaction", itemId: "TX123"); // select_content
analytics.sharesContent(contentType: "statement", itemId: "JUN-2026", method: "whatsapp"); // share
```

### Custom M-Pesa / Wavvy domain events

These are thin wrappers over `logEvent`. Use `logEvent` directly for anything not listed.

```dart
analytics.logSmsParsed(count: 12);                                  // sms_parsed
analytics.logTransactionSynced(source: "sms", count: 12);          // transaction_synced
analytics.logTransactionCategorized(category: "Groceries");        // transaction_categorized
analytics.logStatementImported(period: "2026-06");                 // statement_imported
analytics.logReportExported(format: "pdf");                        // report_exported
analytics.logBudgetCreated(amount: 50000, currency: "KES");        // budget_created
```

### User identity lifecycle

The controller identifies the user automatically on init. Re-sync it around auth changes:

```dart
// After a successful login (auth profile now available)
analytics.setLoggedInUser();

// On logout — clears the analytics identity / cached data
analytics.logoutUser();
```

## Manual init

If you need full control over when Firebase initializes (e.g. you initialize Firebase elsewhere, or
gate analytics behind user consent), set `enableManualInit: true` and call `initialize()` yourself:

```dart
var analytics = Get.put(FirebaseAnalyticsController(
  firebaseOptions: DefaultFirebaseOptions.currentPlatform,
  options: const FirebaseAnalyticsOptions(enableManualInit: true),
));

// Later, once you're ready (e.g. after consent):
await analytics.initialize();
```

## Verifying events (DebugView)

To see events in real time in the Firebase console's **DebugView**:

```bash
# Android
adb shell setprop debug.firebase.analytics.app <your.package.name>

# Disable again
adb shell setprop debug.firebase.analytics.app .none.
```

Then trigger events in the app and watch them appear in **Firebase Console → Analytics → DebugView**.

> If no events appear, check `disableInDebug` / `enabled`: with `disableInDebug: true` (the default),
> events still fire in debug, but with `disableInDebug: false` and `enabled: false` they are
> suppressed. See [Configuration options](#configuration-options).

## Event reference

| Wrapper method | Firebase event | When to use |
|---|---|---|
| `userLogsIn({method})` | `login` | User signs in |
| `userSignsUp({method})` | `sign_up` | New account created |
| `tutorialBegin()` | `tutorial_begin` | Onboarding started |
| `tutorialComplete()` | `tutorial_complete` | Onboarding finished |
| `viewsPlans(items)` | `view_item_list` | Browsing subscription tiers |
| `selectsPlan(item)` | `select_item` | A tier is selected |
| `beginsCheckout(...)` | `begin_checkout` | Subscription flow started |
| `addsPaymentInfo(...)` | `add_payment_info` | Payment details entered (M-Pesa/card) |
| `subscribes(...)` | `purchase` | Subscription paid / renewed |
| `refunds(...)` | `refund` | Subscription refunded |
| `searchesTransactions(term)` | `search` | Searching M-Pesa history |
| `selectsContent(...)` | `select_content` | Tapping a transaction/report |
| `sharesContent(...)` | `share` | Sharing a statement/report |
| `logScreen(name)` | `screen_view` | Manual screen view (auto via `observer`) |
| `logSmsParsed(...)` | `sms_parsed` | M-Pesa SMS parsed |
| `logTransactionSynced(...)` | `transaction_synced` | Transactions synced from a source |
| `logTransactionCategorized(...)` | `transaction_categorized` | A transaction categorized |
| `logStatementImported(...)` | `statement_imported` | Statement imported |
| `logReportExported(...)` | `report_exported` | Report exported |
| `logBudgetCreated(...)` | `budget_created` | Budget created |
| `logEvent(name, parameters)` | *(custom)* | Any other event |
